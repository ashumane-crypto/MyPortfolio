# My Dynamic Portfolio Website 🚀

Welcome to my full-stack portfolio website project! I am building this application step-by-step across 4 phases to display my skills, projects, achievements, and handle dynamic contact messages.

---

## 🗺️ Project Roadmap (4 Phases)

### 💻 Phase 1 — React Frontend (Current Phase)
* **Goal:** Build and test the visual layout.
* **Tasks:** Creating responsive pages, navigation menus, layouts, and external links.
* **Tech:** React.js, JavaScript, HTML5, CSS3

### 🐍 Phase 2 — Python Backend
* **Goal:** Create a fast, robust server side.
* **Tasks:** Building a FastAPI application to serve data and handle contact form submissions.
* **Tech:** Python, FastAPI

### 🗄️ Phase 3 — SQL Database
* **Goal:** Securely store and manage application data.
* **Tasks:** Setting up a database to hold user contact messages and dynamically editable portfolio text.
* **Tech:** MySQL / PostgreSQL

### 🌐 Phase 4 — Integration & Deployment
* **Goal:** Connect everything and launch it live.
* **Tasks:** Wiring React to FastAPI, form validation, fixing CORS configurations, and hosting online.

---

## 🛠️ How to Run the Frontend Locally

To preview Phase 1 on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Go into the folder:**
   ```bash
   cd MyPortfolio
   ```

3. **Install standard tools:** *(Creates your local node_modules folder)*
   ```bash
   npm install
   ```

4. **Launch the site:**
   ```bash
   npm start
   ```
